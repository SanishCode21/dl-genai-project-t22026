# Milestone 1 - Smart MCQ Solver Challenge

## Overview

This branch contains **Milestone 1** of the **DL & GenAI Project: Smart MCQ Solver Challenge**. The goal of this milestone is to build a strong foundation in **Natural Language Processing (NLP)** by exploring the dataset, preprocessing text, generating TF-IDF features, computing cosine similarity, and evaluating baseline models using **MAP@3**.

## Topics Covered

* Exploratory Data Analysis (EDA)
* Text Cleaning and Normalization
* Tokenization and Stop-word Removal
* Vocabulary Analysis
* TF-IDF Vectorization
* Cosine Similarity
* Majority Class Baseline
* TF-IDF Similarity-Based Baseline
* MAP@3 Evaluation Metric

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter/Kaggle Notebook

## Objectives

* Understand the structure of the MCQ dataset.
* Build baseline NLP pipelines for question-answer similarity.
* Establish benchmark performance metrics for future milestones.
